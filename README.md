# Sada-e-Rehmat — website

Static site for GitHub Pages. No build step is needed to host it: every `.html` file in the root is ready to serve.

## Editing

The pages are generated from `_src/` so the header, footer and package data stay consistent:

- `_src/data.py` — the Hajj 2027 packages (collections, hotels, itineraries, PKR and USD prices, add-ons, terms).
- `_src/build.py` — page copy and layout for every page.
- `_src/guides_a.py`, `_src/guides_b.py` — the 18 Hajj and Umrah guides (sections, FAQs, sources, step-by-step scroll stories).
- `_src/content/` — the privacy and cookie policy text.
- `_src/og.mjs` — renders a unique 1200×630 social preview image for every page into `assets/og/`.

After editing, regenerate the pages and the social images, then commit the result:

```bash
python3 _src/build.py
```

```bash
node _src/og.mjs
```

The second command needs Node and Playwright with Chromium. Only re-run it when a page's title, eyebrow, detail line or image changes.

## SEO

Each page has its own title, description, canonical URL, Open Graph and Twitter card with its own image, and BreadcrumbList data. The home page adds TravelAgency, WebSite and FAQPage data; Hajj 2027 adds an ItemList of TouristTrip offers; every guide adds Article and FAQPage data, and the step-by-step guides add HowTo. `sitemap.xml` is regenerated by the build.

Guides were fact-checked on 19 November 2026. Dates (Hajj 2027, Ramadan 2027, Umrah season) and visa and registration rules change, so review the guides before each season.

GitHub Pages ignores folders that start with `_`, so `_src/` is never published.

## Hajj 2027 collections

The twelve Category A packages from the 2027 rate sheet are grouped into four collections:

| Collection | Meaning | Rate-sheet tier | Rate-sheet packages |
|---|---|---|---|
| Sakinah | Tranquillity | Silver | 01, 03, 04 |
| Noor | Light | Gold | 02, 09, 10, 11 |
| Rahmah | Mercy | Platinum | 05, 06, 12 |
| Firdaus | The highest garden | Diamond | 07, 08 |

Each journey keeps its rate-sheet number in `data.py` (`sheet=`) for reference.

## Assets

Optimised photographs live in `assets/img/` as WebP at 1000px and 2000px wide. The original full-size JPEGs in `assets/` are kept as source files but are no longer loaded by the site.

## Motion

`script.js` drives the scroll-linked effects (pinned "scrolly" stories where an image stays in place while the steps scroll past, hero that shrinks into a card, words that light up as you read, stacking collection cards, the pinned horizontal Hajj timeline, full-screen site chapters, parallax and count-ups). All motion is switched off for visitors who set "reduce motion" in their operating system.
